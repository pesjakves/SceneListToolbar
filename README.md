# Scene List Toolbar
![Static Badge](https://img.shields.io/badge/Unity-6.3%20and%20above-white?style=flat&logo=unity&label=UNITY)

Utility that shows all scenes in a dropdown in Toolbar in Unity 6.3. 
A dropdown for quickly loading scenes with an option to load them additively.

<img width="715" height="277" alt="Snímek obrazovky 2026-05-17 214420" src="https://github.com/user-attachments/assets/54f687a3-a624-4421-a94b-60f2ca6d1e57" />


## CONTENT
- a toolbar dropdown with an option for additive loading
- asks to save scenes when switching
- follows a folder structure
- ignores packages folder

## DISCLAIMER
Only works in Unity 6.3 as it uses the Toolbar utility.
